# Expense Tracker App

A simple web application that helps users record and manage their expenses in an organized way.

This project was created as part of the learning process and submission for the **Belajar Membuat Front-End Web untuk Pemula** course on Dicoding.

## Features

- Add expense transactions
- Display a list of transactions
- Delete transactions
- Calculate total expenses
- Display transaction information in an organized way
- Store data using Local Storage
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- Web Storage API (Local Storage)
